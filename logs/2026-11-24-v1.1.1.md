# Version 1.1.1 — 2026/11/24 released

更新範圍：2026/11/23 23:50 起至本次發布前的本地修改（Asia/Taipei）。

## 個人查詢人物區

- 查詢成功後，於統計與篩選區右側顯示角色名稱及人物圖；名稱移至圖片上方，總計橫條不再重複顯示名稱。
- 優先載入 assets/characters/角色名稱/stand1.gif，載入失敗時回退 assets/characters/default.gif。
- 人物區加入暖色圓角外框；窄螢幕改為上下排列。
- 放大角色名稱輸入標籤、輸入框及查詢／更新按鈕文字。
- 重新查詢時清除舊名稱與人物顯示狀態；切換篩選不重複載入人物。

## 排行角色連結

- 排行表格與頒獎台上的角色名稱改為可點擊連結。
- 以 sheet-3.html?name=角色名稱 帶入個人查詢，自動填入並執行一次查詢。
- 角色名稱採 URL 編碼；空白、控制字元或超過 40 字的參數不觸發自動查詢。直接開啟個人查詢頁不發出空白請求。

## 分類統計懸停圖表

- 滑鼠移至總計橫條時展開各分類長條圖，移開隱藏；鍵盤聚焦總計區也可顯示。
- 以角色完整官網勳章資料為基礎，對照 Excel 分類；未知勳章歸入未分類，不受表格搜尋與篩選影響。
- 各分類以相同數量尺度呈現；已擁有使用藍色、未擁有使用紅色，右側顯示兩者數量。未擁有數量為 0 且已擁有數量大於 0 的分類，改用綠色。
- 移除圖表標題與圖例；完整展開所有分類，不提供圖表內部垂直捲軸。
- 放大分類名稱與數量文字，並針對手機版調整欄寬。

## 勳章資料修正

- 「致命魔術」（勳章 ID 1116344）分類由未知改為點裝、難易度由未知改為中等。
- 原始 Excel 的資料庫 T34/U34 與總覽 G34/H34 同步修正，其他檔案部件、圖片、樣式與公式保留。
- 已重新由 Excel 產生本地網頁，總覽與個人查詢資料快照同步更新；此次 GitHub 發布不包含原始 Excel。
