# Version 1.1.0 — 2026/11/22 released

## 勳章排行

- 新增「勳章排行」分頁與全站導覽入口，沿用暖色設計。
- 由神祕谷公開排行頁 https://secretms.com/medal-rankings 分析出資料端點 https://secretms.com/rankings/medal，爬取角色名稱、職業、等級、勳章數；本次快照共 7,449 位角色。
- 排行資料存於 rankings-data.js，顯示擷取時間與官網來源。使用 tools/update-rankings.ps1 可重新擷取；連線或格式檢查失敗時保留既有快照。此版本為靜態快照，未加入定時更新服務。
- 依勳章數由高至低排序，採競賽排名：同分同名次，後續名次跳號（例如 1、2、2、4）。
- 提供角色／職業搜尋、每頁 25 筆、上一頁／下一頁與無結果提示。
- PR = 勳章數嚴格較低的人數 / 全部排行人數 × 100，四捨五入顯示兩位小數。同分不計為贏過；搜尋不影響母體。滑鼠停在 PR 顯示「贏過XXX人!」。

## 前三名與人物圖片

- 搜尋上方新增前三名頒獎台；第一名置中最高，第二與第三名在兩側。只展示名次 1 至 3，並列第二時分站第一名左右並同標 2。
- 頒獎台最終樣式為單一無框線圓角方框，名次數字 Arial；金、銀、銅分別對應 1、2、3 名，第一名為較亮金色。
- 各人物上方依序顯示角色名稱與勳章數；名稱單行，數字不附「枚勳章」。人物與平台留 8px 間距，下方加入兩端留白分隔線。
- 優先載入 assets/characters/角色名稱/stand1.gif；不存在或載入失敗時改用 assets/characters/default.png。目前嘟嘟o、鏡花水玥已有對應動畫。
- 動畫與預設圖皆以原圖尺寸為基礎縮放，桌面 1.25 倍，520px 以下原尺寸；保留各原圖的長寬與高矮差異，不強制等高。
- 重新產生頁面會依 stand1.gif 內容產生版本雜湊，避免更新角色圖後仍讀到舊快取。發布時包含預設圖與所有現有 stand1.gif，不發布其他角色動作素材。

## 表格與搜尋樣式

- 搜尋框與縮短的外框置中，移除冒險家總人數文字。
- 表格字體放大，內文一般字重；名次 1、2、3 數字另以粗體、大字與金銀銅色強調。
- 表格第一列沿用奇偶交錯底色，取消冠軍列特別底色；手機版避免橫向溢出。

## 同次納入的本地更新

- 瀏覽器分頁標題全站統一為「神祕谷勳章查詢系統」，頁面品牌維持「神祕谷勳章系統」。
- 總覽頁品牌與導覽同列對齊；縮窄畫面保留響應式排版。

- 全站底部版本標記更新為 Version 1.1.0 / 2026/11/22 released。
